# AI Counselor

[简体中文](./README.md) | [English](./README_EN.md)

一个能记住过往对话的 AI 心理咨询自助系统，基于 [OpenCode](https://opencode.ai) 的多 agent 架构。

这个仓库提供完整的 **AI 构建指令**。把指令交给你的 OpenCode，让它生成项目、配置依赖并完成检查；构建完成后，在 OpenCode 中开始使用。

## 开始构建

新建一个文件夹，在该文件夹路径下运行OpenCode。打开 [AI_Counselor_SPEC.md](./AI_Counselor_SPEC.md)，复制全文给OpenCode，AI可按照指令开始自动构建。

## 它如何工作

系统将对话、记录和分析交给三个分工不同的 agent：

| 角色 | 负责什么 |
|---|---|
| counselor | 与你对话。以人本主义为主，结合 CBT；回应简短、自然，不写档案 |
| recorder | 咨询结束后，根据原始转录更新档案与会话笔记，只做忠实记录 |
| analyst | 识别跨会话的模式与变化，撰写分析报告和供下次使用的归纳；推测须明确标注 |

对话由插件自动保存。长期记忆以 Markdown 档案保存，每次开始咨询时加载，定期归纳后继续用于下一次对话。

## 日常使用

构建完成后，在项目目录启动 OpenCode。每次新咨询，按tab键将OpenCode切换到Counselor，然后输入：

```text
/start
```

接着开始对话。结束时执行：

```text
/end
```

需要回顾时，可以选择：

| 命令 | 作用 |
|---|---|
| `/start` | 加载记忆档案，以咨询师身份开场 |
| `/end` | 记录当前咨询尚未处理的内容，更新档案和会话笔记 |
| `/analyze` | 基于转录与档案生成深度分析报告 |
| `/weekly` | 生成分析报告，归档旧归纳，更新下次开场使用的归纳 |

同一天可以进行多次咨询。重复 `/end` 且没有新增消息时不重复记录；同一主会话继续对话后，再次 `/end` 只处理新增内容。`/weekly` 按需手动执行。

## 构建后会生成什么

```text
.opencode/
  agents/             咨询师、记录员、分析员定义
  commands/           四个日常命令
  plugins/            自动转录与来源会话识别插件
records/
  profile.md          稳定背景与重要关系
  timeline.md         关键事件时间线
  themes.md           反复出现的主题
  insights.md         深度分析报告
  transcripts/        原始对话转录
  sessions/           会话笔记与已处理消息标记
  summaries/          当前归纳及历史归档
```

完整目录、文件模板和插件行为规格均包含在构建指令中。该文档不包含作者的真实咨询记录。

## 隐私与使用边界

`records/` 是你的私人咨询资料，构建时会被 `.gitignore` 整体排除。不要将其提交到 GitHub，也不要在 Issue、截图或使用示例中公开真实咨询内容。

本系统用于自助陪伴与自我理解，不能替代持证心理治疗或精神科诊疗。内置危机协议，引导在需要时联系专业援助，请在构建阶段按所在地调整。
